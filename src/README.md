# src/

Código da aplicação. `main.tsx` é a única entrada JS; o HTML de entrada permanece em `../index.html`.

| Arquivo / pasta | Papel |
| --- | --- |
| `main.tsx` | Mount do React, import do CSS agregado, normalização de URL. |
| [`app/`](app/README.md) | Router, títulos de rota, `App`. |
| [`pages/`](pages/README.md) | Uma página por rota. |
| [`components/`](components/README.md) | UI agrupada por domínio. |
| [`data/`](data/README.md) | Conteúdo estático tipado. |
| [`lib/`](lib/README.md) | Áudio, storage, academia, basename. |
| [`styles/`](styles/README.md) | Tokens e folhas por superfície. |
| [`types/`](types/README.md) | Contratos TypeScript por domínio. |
