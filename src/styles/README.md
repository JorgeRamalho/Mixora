# src/styles/

CSS da aplicação. `index.css` é o único import em `src/main.tsx`.

| Arquivo | Papel |
| --- | --- |
| `index.css` | `@import` das folhas abaixo, na ordem de cascata. |
| `base.css` | Tokens (`:root`), reset, tipografia, utilitários. |
| `layout.css` | Header, shell, ticker, páginas, formulário. |
| `hero.css` | Visor digital, waveform, chips. |
| `mixer.css` | Decks, jog wheels, EQ, faders. |
| `panels.css` | Academia, rádio, catálogo, cadastro DJ. |
