# src/pages/

Uma página por rota. Cada arquivo só importa o componente de domínio e, se precisar, um dado de `data/` ou `lib/`.

| Arquivo | Rota |
| --- | --- |
| `HomePage.tsx` | `/` |
| `MixerPage.tsx` | `/mixer` |
| `AcademyPage.tsx` | `/academia` |
| `RadioPage.tsx` | `/radio` |
| `CatalogPage.tsx` | `/catalogo` |
| `DownloadPage.tsx` | `/download` |
| `DjPage.tsx` | `/dj` |
